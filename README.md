# The Ancient Atlas

> A hand-curated map of the world's most significant ancient sites, organized by region, era, and the creators who have walked them.

**Live site :** [theancientatlas.com](https://theancientatlas.com)

The atlas is an editorial instrument for reading the deep past. It catalogs **293 ancient sites** across nine regions with **320 YouTube walkthroughs** from **32 creators**, plus a Library of field guides (Megaliths, Stone Circles, more in progress). Each site card includes coordinates, era, civilization, and direct deep-links to videos that walk the ground.

This repository is the source of truth. Pushes to `main` auto-deploy to Netlify.

## The atlas in one paragraph

You see a map of the world, with ~300 dots in champagne gold. Each dot is a real ancient site : a pyramid, a stone circle, a rock-cut temple, a megalithic wall, a settlement. Clicking a dot opens a card with the site's name, age, civilization, coordinates, and any YouTube walkthroughs that exist for it. Multi-site documentaries are flagged so you can jump to the specific moment about that site. The map is ad-free, hand-curated, and free to explore.

What the atlas does that YouTube alone doesn't : aggregate multiple credible voices on the same place, organize them spatially and chronologically, and let you scrub a climate slider to see how the Earth looked when the site was built.

## How to contribute

The short version :

1. Read [CONTRIBUTING.md](CONTRIBUTING.md) — five-minute editorial guide
2. Fork this repo
3. Edit `data/videos.json` (or `data/sites.json` for new sites)
4. Submit a pull request
5. A maintainer reviews and merges

The friction-free version :

1. Visit [theancientatlas.com/contribute](https://theancientatlas.com/contribute)
2. Paste a YouTube URL (single or bulk)
3. Pick a site from the dropdown
4. Click "Submit" — opens a pre-filled GitHub PR
5. A maintainer reviews and merges

See [docs/EDITORIAL_GUIDELINES.md](docs/EDITORIAL_GUIDELINES.md) for what makes a walkthrough atlas-worthy.

## Local development

```bash
# Install dependencies
pip install --break-system-packages Pillow PyYAML

# Build index.html from data/
python3 scripts/build.py

# Open the result locally
open public/index.html

# Re-run audit before any deploy
python3 scripts/audit-videos.py

# Regenerate the share image if site count changed
python3 scripts/generate-og.py
```
