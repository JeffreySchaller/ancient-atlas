# Brittany and mainland Italy photo collection

Reviewed 24 October 2026. Adds 18 credited Commons photographs across eight monuments: Gavrinis, Barnenez and Locmariaquer in Brittany; Porta Saracena at Segni, Alba Fucens, the Bomarzo rock-cut monument, Alatri Acropolis and Norba in mainland Italy. The existing 70-photo Sardinia/Corsica collection is retained intact. Total: 88 photographs at 43 sites.

## Identification and selection

Commons file titles, categories and descriptions were checked against the named monuments, then all chosen images were visually reviewed. The selection includes whole structures, passage entrances, exposed chambers, polygonal gateways, masonry details, a rock-cut staircase and the engraved capstone at Table des Marchand. Photographer, stated reusable licence, licence URL, Commons page, conversion note and image dimensions are retained per image in data/site-photos.json.

The distant Gavrinis view is explicitly captioned as a view across the water. The first two searches for carvings mainly returned historical book scans or unrelated material, so those were not presented as modern photographs. A duplicated distant view and a heavily watermarked gateway photo were omitted. The engraved capstone image belongs to Table des Marchand at Locmariaquer, not Gavrinis, even though the metadata discusses the relationship between the monuments. Alba Fucens aqueduct photographs from the outlying Arci area were excluded from the city-wall pin.

## Precise map locations

Porta Saracena has a new separate pin at 41.6979901, 13.016936, rather than attaching its gateway photos to Segni's town centre. The named Wikidata object Q87146870 agrees with the nearby camera coordinates on two Commons gateway photographs. Official identity/reference: https://www.italia.it/en/lazio/segni/the-porta-saracena-and-the-cyclopean-walls . Its era filter uses a representative approximate year, not a newly asserted precise construction date.

Five existing pins were refined from coarse locations to the relevant monument/archaeological complex. Before/after values and source links are in brittany-italy-coordinate-review.json. Gavrinis uses the cairn object Q2933238, not the island centroid. Locmariaquer uses Table des Marchand in the contiguous megalithic complex. Alatri uses the acropolis object rather than the modern town. Alba Fucens uses the ancient-site object. Norba's existing pin is retained within the archaeological footprint; conflicting object coordinates were not arbitrarily substituted.

Bomarzo uses the archaeological field account's explicit IGM/GPS location, 42°28′52.75″N, 12°15′51.30″E: https://archeologiaepaesaggio.wordpress.com/2021/02/15/la-piramide-di-bomarzo/ . The selected photograph's camera coordinates (42.481433, 12.264261) agree within about 13m. A tourism page publishes a conflicting point several kilometres away; that point was not used. The existing description was made cautious about the uncertain date and function.

The existing duplicate Carnac entries were noticed, but were not treated as two photo-only gaps or merged during this focused collection. No existing film association or timestamp was changed. A location audit is not a blanket validation of older historical descriptions elsewhere in the Atlas.

## Website and verification

The photograph directory now derives region filters from photo collection metadata, instead of treating every non-Corsican photo as Sardinian. Direct regional URLs use /photos/?region=Brittany and /photos/?region=Mainland%20Italy. Map galleries, static site pages and the mobile photo feed use the existing shared infrastructure.

Validation covers exact canonical bindings, image/credit/licence metadata and local assets, preservation of previous photographs and all films/timestamps, desktop/mobile region filtering and direct links, photograph-only gateway navigation, and the directory without JavaScript.
